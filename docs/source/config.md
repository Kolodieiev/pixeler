# Конфігурація Pixeler

Для зручності усі доступні налаштування Pixeler зібрано в заголовкових файлах в каталозі `/src/config`.
Рекомендується уважно ознайомитись з цими файлами.
Редагуючи їх вміст, можна підключати або відключати певний функціонал, та налаштовувати параметри периферії.
Якщо в проєкті не використовується периферія, налаштування якої є в файлах налаштувань, на ці налаштування можна не зважати і залишити як є.

::: {important}
Деякий функціонал, наприклад GUI, є глобальним та буде збиратися з прошивкою, якщо його не вимкнено через відповідний прапор.
Тому варто читати коментарі біля визначень в файлах налаштувань.
:::

Більш детально вміст деяких файлів конфігурації буде описано у розділах документації, присвячених відповідному функціоналу.
