### Конфігурація Pixeler

Усі доступні налаштування фреймворку та периферії зібрано в заголовкових файлах у каталозі `/src/config/`. 

Редагуючи вміст цих файлів, можна вмикати або вимикати окремі підсистеми фреймворку, обирати драйвери та задавати апаратні параметри (номери пінів, частоти шин, розміри буферів тощо). Якщо у вашому проєкті певна периферія не використовується, відповідні їй налаштування можна залишити без змін.

<br>

::: {important}
Деякий функціонал (наприклад, графічна підсистема `GRAPHICS_ENABLED`) є глобальним і за замовчуванням компілюється разом із прошивкою, якщо його не вимкнути через відповідний прапор препроцесора. Рекомендується уважно переглянути коментарі біля макросів у файлах конфігурації перед першою збіркою.
:::

<br>

#### Основні файли налаштувань у `/src/config/`

| Файл конфігурації | Призначення |
| :--- | :--- |
| **`graphics_config.h`** | Увімкнення GUI (`GRAPHICS_ENABLED`), вибір шини та драйвера дисплея (`Arduino_GFX`), роздільна здатність екрана та канвасу, орієнтація. |
| **`input_config.h`** | Реєстрація віртуальних кнопок та їх прив'язка до пінів GPIO, увімкнення тачскріна (`TOUCHSCREEN_SUPPORT`), USB-клавіатури (`KEYBOARD_SUPPORT`), зовнішнього I2C-вводу (`EXT_INPUT`) та таймінги блокування кнопок. |
| **`sd_config.h`** | Налаштування інтерфейсу SD-карти пам'яті (вибір SPI або SD_MMC, піни підключення, частота шини). |
| **`i2c_config.h`** | Налаштування пінів шини I2C (використовується для тачскріна, допоміжного МК або іншої периферії). |
| **`coprocessor_config.h`** | Налаштування адреси та команд для допоміжного мікроконтролера-співпроцесора по шині I2C. |

<br>

Детальний розбір специфічних макросів наведено у відповідних розділах документації ([Підключення дисплея](display.md), [Користувацький ввід](input.md), [Карта пам'яті](sd.md)).
