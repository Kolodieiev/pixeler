# Підключення дисплея

Pixeler підтримує вивід зображення на дисплей через модифіковану бібліотеку `Arduino_GFX`. 
Не всі дисплеї з оригінальної бібліотеки підтримуються. 
В першу чергу це стосуєтсья дисплеїв, які підключаються по шині I2C.
При цьому для більшості кольорових дисплеїв сумісніть збережено.
<br>

Одночасно Pixeler може працювати лише з одним дисплеєм.
<br>

Базові налаштування бібліотеки та дисплея знаходяться в файлі `config/graphics_config.h`.
Для однакового підключення різних типів шин та драйверів дисплеїв, їх налаштування відбувається за допомогою макросів.
Тому в `graphics_config.h` необхідно коректно налаштувати ці макроси, щоб відповідні значення були підставлені в код на етапі компіляції.
<br>
<br>

Базовий приклад налаштування ШИНИ дисплея:
```cpp
// Клас шини.
#define BUS_TYPE Arduino_ESP32SPI   

// Парапор, який вказує чи є шина спільною для декількох пристроїв, 
// в першу чергу це стосується SPI.
#define IS_COMMON_BUS false    

// Параметри, які передаються до класу шини.
#define BUS_PARAMS TFT_DC, TFT_CS, TFT_SCLK, TFT_MOSI, TFT_MISO, SPI_PORT, IS_COMMON_BUS  

// В коді ініціалізації ці макроси буде зібрано наступним чином
BUS_TYPE _bus{BUS_PARAMS};
```
<br>
<br>

Базовий приклад налаштування дисплея:
```cpp
// Клас драйвера дисплея.
#define DISP_DRIVER_TYPE Arduino_ST7789

// Параметри класу драйвера дисплея БЕЗ адреси шини. 
#define DISP_DRIVER_PARAMS TFT_RST, DISPLAY_ROTATION, IS_IPS_DISPLAY, DISPLAY_WIDTH, DISPLAY_HEIGHT  

// В коді ініціалізації ці макроси буде зібрано наступним чином
Arduino_GFX* _output = new DISP_DRIVER_TYPE(&_bus, DISP_DRIVER_PARAMS);
```
<br>

З параметрами та їх порядком передачі в конструктор для певного дисплея чи шини,
можна ознайомитися самостійно у відповідних файлах драйверів бібліотеки `Arduino_GFX`.
<br>
<br>

З не зовсім очевидних налаштувань, потрібно розглянути наступні.
```cpp
#define UI_WIDTH 240   // Ширина UI(канвасу).
#define UI_HEIGHT 320  // Висота UI(канвасу).

#define DISPLAY_WIDTH 240   // Ширина дисплея.
#define DISPLAY_HEIGHT 320  // Висота дисплея.
```

В даному випадку значення однакові, проте в інших прикладах вони можуть відрізнятися
через те, що Pixeler дозволяє виводити GUI не на увесь екран.
Це може бути особливо корисним, якщо прошивка з одного пристрою, 
запускається на іншому з більшим дисплеєм, при цьому GUI ще не портовано на цей дисплей.
<br>
<br>

Для деяких, особливо це стосується маленьких дисплеїв, можуть виникнути проблеми з виводом зображення в не стандартній орієнтації.
Зазвичай, це проявляється тим, що зображення частково виводиться за дисплеєм з однієї або двох сторін. 
Вирішуєтсья така проблема коректним встановленням розмірів GUI відносно дисплея, 
та встановленням коректного зміщення зображення, для певної орієнтації.

До прикладу налаштування дисплея на платі Lilka v2 мають наступний вигляд:

```cpp
#define DISPLAY_ROTATION 3  // Стартова орієнтація дисплея.

#define UI_WIDTH 280   // Ширина UI.
#define UI_HEIGHT 240  // Висота UI.

#define DISPLAY_WIDTH UI_HEIGHT  // Ширина дисплея.
#define DISPLAY_HEIGHT UI_WIDTH  // Висота дисплея.

#define DISP_DRIVER_PARAMS TFT_RST, DISPLAY_ROTATION, IS_IPS_DISPLAY, DISPLAY_WIDTH, DISPLAY_HEIGHT, 0, 0, 0, 20
```
