### Ігровий рушій

Pixeler містить вбудований 2D ігровий рушій для розробки двовимірних ігор під мікроконтролери лінійки ESP32 з підтримкою ігрових сцен, спрайтів, колізій та мережевої синхронізації по Wi-Fi.

<br>

::: {note}
Детальна документація цього розділу перебуває в процесі написання. Наразі ознайомитися з архітектурою ігрових сцен та об'єктів можна на базі готових ігрових прикладів (зокрема, Шахи та 2D RPG) у каталозі [`examples/ESP32S3/Perfect-Devboard`](https://github.com/Kolodieiev/pixeler/tree/master/examples/ESP32S3/Perfect-Devboard) та у заголовкових файлах каталогу `src/game/`.
:::
