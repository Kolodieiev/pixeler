### Ігровий звук (`SFX` та `SfxPlayer`)

У кожну ігрову сцену (`IGameScene2D`) вбудовано багатопотокову звукову підсистему на базі класів **`SFX`** (`#include "game/sfx/SFX.h"`) та **`SfxPlayer`** (`#include "game/sfx/SfxPlayer.h"`). 

Екземпляр плеєра-мікшера створюється у сцені автоматично (поле **`_sfx_player`**) і передається за посиланням у конструктор кожного створеного ігрового об'єкта (`IGameObject2D`). Це дозволяє будь-якому об'єкту або самій сцені в довільний момент додавати звукові ефекти до загального міксу. Плеєр на окремому ядрі мікроконтролера (Core 0) у реальному часі склеює семпли всіх активних звуків, захищає сигнал від переповнення (кліпінгу) та виводить об'єднаний потік на цифровий аудіовихід I2S (`_i2s_out`).

<br>

#### 1. Підготовка та конвертація звукових файлів (`.wav`)

Для того щоб завантажувач `WavLoader` зміг успішно розпізнати заголовок файлу, а звуковий рушій — без додаткового навантаження на процесор мікшувати звукові ефекти в реальному часі, аудіофайли необхідно попередньо конвертувати у відповідний нестиснений формат **WAV**.

Для підготовки звуків рекомендується використовувати безкоштовний аудіоредактор **Audacity** (*Файл ➔ Експортувати аудіо...*) з такими обов'язковими параметрами:
* **Формат:** `WAV (Microsoft)`
* **Канали:** `Моно` (Mono)
* **Частота дискретизації:** `16000 Гц`
* **Кодування:** `Signed 16-bit PCM`

#### 2. Звукова доріжка (`SFX`)

Клас **`SFX`** є легкою обгорткою над буфером сирих аудіоданих (PCM), завантажених в оперативну пам'ять як `AudioResource`. Він **не копіює** сам масив байтів звуку, а лише зберігає вказівник на нього (`const uint8_t*`), розмір даних, поточну позицію відтворення (`_current_sample`), індивідуальну гучність та налаштування повтору.

##### Основні методи `SFX`

| Метод | Опис |
| :--- | :--- |
| **`SFX(data_buf, data_size)`** | Створює об'єкт звукової доріжки на основі вказівника на буфер аудіоданих та його розміру в байтах (гучність за замовчуванням — `50%`). |
| **`setVolume(volume)`**, **`getVolume()`** | Встановлює або повертає індивідуальну гучність доріжки у відсотках (`0..100`). |
| **`setOnRepeat(repeat)`** | Якщо `true` — після досягнення кінця буфера доріжка автоматично починає грати спочатку (використовується для фонової музики або тривалих шумів, як-от звук двигуна чи дощу). |
| **`setFiltrationLvl(lvl)`** | Встановлює поріг шумоподавлення (Noise Gate). За замовчуванням `1` (без фільтрації). Дозволяє відсікати тихі фонові шуми квантування у 16-бітних записах. |
| **`play()`**, **`stop()`** | Скидає позицію на початок і запускає відтворення доріжки або примусово зупиняє її. |
| **`isPlaying()`** | Повертає `true`, доки доріжка активна і ще не дійшла до кінця буфера. |
| **`clone()`** | Створює в купі (`new`) і повертає незалежну копію об'єкта `SFX`, яка посилається на той самий буфер аудіоданих у пам'яті. |

<br>

#### 3. Багатопотоковий мікшер (`SfxPlayer`)

Клас **`SfxPlayer`** керує списком усіх активних звукових доріжок на сцені та у фоновому потоці FreeRTOS мікшує їхні семпли у вихідний буфер I2S.

##### Життєвий цикл звуків у мікшері та патерн `clone()`
Важливою особливістю `SfxPlayer` є **автоматичне керування пам'яттю активних доріжок**:
1. Коли ви передаєте вказівник `SFX*` у метод **`addSFX(sfx)`**, плеєр бере цей об'єкт під своє володіння.
2. Щойно одноразова доріжка (`_on_repeat == false`) дограє до кінця, фонова задача мікшера **автоматично викликає для неї `delete` і видаляє її зі списку**.
3. Тому в сцені або в об'єкті зручно створити один «еталонний» шаблон звуку `SFX` (налаштувавши йому гучність і фільтрацію), а під час кожного пострілу, кроку чи удару передавати у плеєр його швидкий клон: **`_sfx_player.addSFX(_step_sfx_tmpl->clone())`**. Завдяки цьому один і той самий звук може накладатися сам на себе декілька разів одночасно без дублювання WAV-буфера в пам'яті!

##### Основні методи `SfxPlayer`

| Метод | Опис |
| :--- | :--- |
| **`startMix()`** | Запускає фонову FreeRTOS-задачу міксування звуку на Core 0 (перед запуском шина `_i2s_out` має бути ініціалізована). |
| **`addSFX(sfx)`** | Потокобезпечно додає доріжку `SFX*` до міксу та повертає її унікальний ідентифікатор `uint16_t id` (`> 0`). |
| **`removeSFX(id)`** | Примусово зупиняє доріжку за її `id`, видаляє зі списку міксування та звільняє пам'ять об'єкта `SFX` (використовується для зупинки зациклених звуків з `setOnRepeat(true)`). |
| **`clear()`** | Миттєво зупиняє та видаляє з пам'яті всі активні звукові доріжки на сцені. |
| **`pauseResume()`** | Ставить відтворення всього міксу на паузу або відновлює його (наприклад, під час відкриття ігрового меню паузи `_game_menu`). |
| **`setMasterVolume(vol)`**, **`getMasterVolume()`** | Встановлює або повертає загальну майстер-гучність мікшера сцени (`0..100%`). |

#### 4. Завантаження аудіоресурсів (`_res` та `AudioResource`) і приклад використання

Завантаження `.wav` та `.bmp` файлів із SD-карти в оперативну пам'ять (або PSRAM) виконується через глобальний об'єкт менеджера ресурсів **`_res`** (`#include "manager/ResManager.h"`).

Менеджер автоматично визначає тип файлу за його розширенням (`.wav` або `.bmp`), викликає відповідний завантажувач (`WavLoader` або `BmpLoader`) і повертає унікальний числовий ідентифікатор ресурсу (`uint32_t res_id > 0`). Додатково ресурсу можна присвоїти текстове ім'я (`res_name`), щоб пізніше знаходити або видаляти його за назвою.

```cpp
#include "manager/ResManager.h"
#include "res/AudioResource.h"

// 1. В ініціалізації сцени завантажуємо WAV-файли через глобальний об'єкт _res та запускаємо мікшер:
void MyGameScene::initAudio()
{
  // Завантажуємо файли з SD-карти (можна зберегти числовий ID або задати символьне ім'я)
  uint32_t bg_res_id = _res.load("/game/audio/ambient.wav", "ambient");
  uint32_t hit_res_id = _res.load("/game/audio/hit.wav", "hit");

  // Запускаємо фонову задачу мікшера (шина _i2s_out має бути попередньо ініціалізована)
  _sfx_player.setMasterVolume(80);
  _sfx_player.startMix();

  // Отримуємо ресурс за його числовим ID
  const IResource* res_bg = _res.getResByID(bg_res_id);
  if (res_bg && res_bg->getType() == IResource::TYPE_AUDIO)
  {
    SFX* bg_sfx = new SFX(static_cast<const uint8_t*>(audio_bg->getData()), audio_bg->getDataSize());
    bg_sfx->setVolume(40);
    bg_sfx->setOnRepeat(true); // Грати фонову тему безкінечно по колу
    _bg_music_id = _sfx_player.addSFX(bg_sfx);
  }

  // Або отримуємо ресурс за його текстовим іменем ("hit")
  const IResource* res_hit = _res.getResByName("hit");
  if (res_hit && res_hit->getType() == IResource::TYPE_AUDIO)
  {
    // Створюємо еталонний шаблон для короткого звуку удару
    _hit_sfx_tmpl = new SFX(static_cast<const uint8_t*>(audio_hit->getData()), audio_hit->getDataSize());
    _hit_sfx_tmpl->setVolume(90);
  }
}

// 2. У будь-який момент гри (у сцені або всередині IGameObject2D через поле _audio):
void HeroObj::onAttack()
{
  // Додаємо клон шаблону до мікшера — після програвання плеєр сам видалить клон із пам'яті!
  if (_hit_sfx_tmpl)
  {
    _audio.addSFX(_hit_sfx_tmpl->clone());
  }
}

// 3. При виході зі сцени зупиняємо зациклений звук і вивантажуємо ресурси з пам'яті:
void MyGameScene::stopMusic()
{
  if (_bg_music_id > 0)
  {
    _sfx_player.removeSFX(_bg_music_id);
    _bg_music_id = 0;
  }

  // Звільняємо WAV-буфери з глобального менеджера ресурсів за іменем або ID:
  _res.deleteResByName("ambient");
  _res.deleteResByName("hit");
}
```
