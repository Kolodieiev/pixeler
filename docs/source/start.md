# Швидкий старт

Для збірки прошивки на Pixeler, необхідно першим кроком встановити та налаштувати VS Code.
<br>
Далі необхідно встановити venv командою

    sudo apt install python3-venv

Та утиліти для роботи з архівами 

    sudo apt install xz-utils liblzma-dev

Після цього в менеджері розширень VS Code знайти розширення `Pioarduino` та встановити його.
Зверніть увагу, не `Platformio`, а саме `Pioarduino`.
Pioarduino це форк Platformio, що підтримує останні версії Arduino та ESP-IDF.

::: {important}
Обидва розширення використовують папку `.platformio`, тому можуть перезаписувати критичні файли одне одному та ламати збірку.
Якщо `Platformio` активно використовується для збірки інших проєктів найкраще, ДО встановлення `Pioarduino`, перейменувати цей каталог 
та відключити розширення `Platformio` задля уникнення конфліктів.
:::

Для швидкого тестування графічного інтерфейсу на Pixeler в Linux, рекомендуєтсья скористатися його портованою версією: 
<a href="https://github.com/Kolodieiev/pixeler4pc" target="_blank">Pixeler4PC на Github</a>
