### Швидкий старт

Для збірки та завантаження прошивок на базі **Pixeler** використовується редактор **VS Code** разом із розширенням **Pioarduino**.

<br>

#### 1. Підготовка системи (Linux)

Перед встановленням плагіна необхідно переконатися, що в системі встановлено віртуальне середовище Python (`venv`) та бібліотеки для роботи з архівами:

```bash
sudo apt update
sudo apt install python3-venv xz-utils liblzma-dev
```

<br>

#### 2. Встановлення Pioarduino у VS Code

1. Встановіть та відкрийте **Visual Studio Code**.
2. Перейдіть на вкладку розширень (**Extensions**, комбінація `Ctrl+Shift+X`).
3. Знайдіть у пошуку та встановіть розширення **`Pioarduino`** (зверніть увагу: саме **Pioarduino**, а не стандартний PlatformIO).

**Pioarduino** — це актуальний форк PlatformIO, який підтримує найновіші версії ядер Arduino та ESP-IDF для мікроконтролерів лінійки ESP32 / ESP32-S3 / ESP32-P4.

<br>

::: {important}
Обидва розширення (PlatformIO та Pioarduino) за замовчуванням використовують системний каталог `~/.platformio`, через що можуть перезаписувати критичні файли одне одного та ламати збірку. Якщо ви вже активно використовуєте класичний PlatformIO для інших проєктів, рекомендується **ДО встановлення Pioarduino** тимчасово перейменувати каталог `~/.platformio` та вимкнути розширення PlatformIO у VS Code, щоб уникнути конфліктів.
:::

<br>

#### 3. Швидка розробка інтерфейсу на ПК (`Pixeler4PC`)

Щоб не витрачати час на постійну компіляцію та перепрошивання мікроконтролера під час верстки екранів і налаштування віджетів, рекомендується скористатися портованою на Linux графічною частиною фреймворку:

👉 <a href="https://github.com/Kolodieiev/pixeler4pc" target="_blank"><b>Репозиторій Pixeler4PC на GitHub</b></a>

Створений у `Pixeler4PC` код макетів та віджетів можна без змін переносити в основну прошивку мікроконтролера.
