# 🎮 Альтернативна прошивка для Lilka v2

![Platform](https://img.shields.io/badge/Platform-ESP32--S3-blue?style=flat-square&logo=espressif)
![Board](https://img.shields.io/badge/Board-Lilka%20v2-orange?style=flat-square)
![Framework](https://img.shields.io/badge/Framework-Pixeler-purple?style=flat-square)
![Build](https://img.shields.io/badge/Build-pioarduino-00599C?style=flat-square)

Портована альтернативна прошивка на базі C++ фреймворку **[Pixeler](https://kolodieiev.github.io/pixeler/)**, адаптована для DIY-консолі **[Lilka v2](https://docs.lilka.dev/uk/latest/)** (ESP32-S3-WROOM-1-N16R8).

> **Pixeler** об'єднує швидкий вивід графіки (модифікований `Arduino_GFX`), систему ізольованих екранів-контекстів, набір UI-віджетів, потокобезпечну роботу з SD-картою, 2D-ігровий рушій та підтримку Lua-скриптів в єдину легку екосистему поверх Arduino та ESP-IDF.

---

## ✨ Основні можливості

* **Швидкий GUI та контексти** — плавний інтерфейс із готовими віджетами та автоматичним керуванням пам'яттю при перемиканні екранів.
* **Робота з SD-картою** — швидкий файловий менеджер із підтримкою PSRAM та фонових операцій без блокування інтерфейсу.
* **2D-рушій та ігри** — підтримка спрайтів, ігрових сцен, звуку та мережевої взаємодії по Wi-Fi.
* **Скриптинг на Lua** — запуск власних програм та інтерфейсів без перепрошивки пристрою.
* **Адаптація під Lilka v2** — налаштована конфігурація дисплея, кнопок керування та периферії плати.

## 🕹️ Керування

Керування прошивкою виконується кнопками джойстика та кнопками **A** і **B**:

| Кнопка | Дія |
| :--- | :--- |
| **Джойстик (↑ ↓ ← →)** | Навігація по меню, списках та елементах інтерфейсу |
| **A** *(коротке натискання)* | Підтвердження / вибір / основна дія |
| **A** *(довге утримування)* | Виклик контекстного меню *(якщо підтримується поточним екраном)* |
| **B** | Назад / скасування / вихід |

## 📂 Підготовка SD-карти (Музика, Радіо, Книги)

Для тестування вбудованого музичного плеєра та читалки організуйте файли в корені карти пам'яті за такою структурою:

```text
SD/
├── music/
│   ├── Rock/              # Кожен підкаталог — окремий плейлист
│   │   ├── track_01.mp3
│   │   └── track_02.mp3
│   └── Radio/
│       └── station.fm     # Файл із прямим посиланням на онлайн-потік
└── books/
    ├── Sci-Fi/            # Підкаталоги за жанром або серією
    │   └── book_01.txt
    └── Fantasy/
        └── book_02.txt

```

* **🎵 Музичний плеєр:** створіть у корені SD-карти каталог `music` та додайте до нього підкаталоги — кожен окремий підкаталог відображається як окремий плейлист.
* **📻 Онлайн-радіо:** покладіть у будь-який підкаталог усередині `music` текстовий файл із розширенням `.fm`, що містить пряме посилання на аудіопотік.
* ⚠️ У файлі `.fm` **не повинно бути** переносів рядків, пробілів чи будь-яких зайвих символів — лише чистий URL.
* 📶 Для відтворення онлайн-радіо необхідно **заздалегідь підключитися до Wi-Fi роутера** з доступом до інтернету.


* **📖 Читалка книг:** створіть у корені SD-карти каталог `books` та розміщуйте книги у форматі `.txt` по підкаталогах (наприклад, за серіями чи жанрами).

## ⚡ Швидке ознайомлення (готові бінарники)

Якщо ви хочете спробувати прошивку **без самостійної збірки**, у каталозі [`bin/`](https://www.google.com/search?q=./bin) (`examples/ESP32S3/Lilka_v2/bin`) вже знаходяться готові зібрані бінарні файли та детальна інструкція з їхнього встановлення на плату.

## 🛠️ Збірка з вихідного коду

Для самостійної збірки використовується **виключно `pioarduino**` (детальніше про налаштування середовища — у [документації Pixeler](https://kolodieiev.github.io/pixeler/)).

1. Клонуйте повний репозиторій фреймворку:
```bash
git clone [https://github.com/Kolodieiev/pixeler.git](https://github.com/Kolodieiev/pixeler.git)

```


2. Перейдіть до каталогу проєкту:
```
pixeler/examples/ESP32S3/Lilka_v2

```


3. Відкрийте цю папку як проєкт у **VS Code** із встановленим розширенням **pioarduino**.
4. Підключіть **Lilka v2** через USB та виконайте збірку і прошивку (`Build` / `Upload`).
